2. Restore from the newest snapshot

Patches every account back to its saved values. Leave the box empty for a dry run that writes nothing. Type YES to apply.
Honest limit: this API has no delete, so accounts the pipeline created cannot be removed. They are marked Inactive with an explanatory note instead.

3. Export the ledger to a spreadsheet

Every proposal and decision as a CSV, with the evidence in plain English. Open sheets.new, then File → Import → Upload, and a non-technical reviewer can read the whole queue and flag anything wrong.
One way on purpose: editing the sheet changes nothing here.

4. Clear local run history

Deletes every run, proposal and API log on this machine. After a restore, this makes the next run behave as if it were the first. It does not touch the CRM.
